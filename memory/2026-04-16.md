# 2026-04-16

## Nexplay UI y arquitectura
- Se consolidó la separación UX entre `/panel` (Centro de control operativo con KPIs diarios) y `/dashboard` (área de configuración/admin sin KPIs del día).
- Se definió y se implementó un estándar para manejo de imágenes en NEXPLAY: módulo backend `Files` con endpoint `POST /files/upload-image`, almacenamiento de archivos en `backend/uploads/<kind>/...` y exposición estática bajo `/uploads/...`.
- Todos los formularios actuales que usan imágenes (logo de tenant, imagen de tienda, imagen de zona, cover de juego y avatar de usuario) ahora incluyen botón de upload que llama al nuevo endpoint y autocompleta el campo URL con la ruta pública resultante.
- Se fijó regla permanente: todo campo futuro que represente imagen/icono/foto/avatar/cover debe incluir siempre opción de upload integrada contra el estándar de archivos definido.
